# R Projects

A structured series of R projects, learned alongside a parallel Python track, building toward data science, data analytics, and machine learning skills.

## About

Each project in this repository focuses on core R concepts — variables, vectors, data frames, and visualization — with an emphasis on working with real, tabular data rather than isolated syntax exercises. R is being learned specifically for its strengths in statistics, data analysis, and plotting, alongside a separate Python track used for general-purpose programming and machine learning.

## Projects

### 1. Basics (`basics.R`)

An introduction to R syntax: variables, assignment with `<-`, and `paste()` for building formatted strings. First script in the series — focused on getting comfortable with the RStudio environment and core syntax rules.

### 2. Football Stats Analysis (`football_stats.R`)

A small data analysis project using a hand-built dataset of football player stats (goals, assists, matches played). Builds a data frame, calculates a goals-per-match column, filters for the top scorer, and visualizes goals per player with a bar chart (`goals_by_player.png`).

## Tech Stack

- **Language:** R
- **Environment:** RStudio
- **Core concepts used:** vectors, data frames, base R plotting (`barplot`)
- **Tools:** Git & GitHub

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rolandzacx-eng/r-projects.git
cd r-projects
```

Open any `.R` file in RStudio and run it with **Source** (or select all and press Ctrl+Enter).

## What This Series Covers

- Core syntax: variables, assignment, functions
- R's atomic types and vectors, including vectorized operations
- Data frames: building, indexing with `$`, and filtering rows
- Base R plotting for quick visualizations
- R's documentation system (`?function_name`) and style conventions
